# 下架时间

## 接口描述[​](https://developers.binance.com/docs/zh-CN/derivatives/usds-margined-futures/market-data/rest-api/Delist-Schedule#%E6%8E%A5%E5%8F%A3%E6%8F%8F%E8%BF%B0 "接口描述的直接链接")

合约团队会在下架公告后发布后更新`Get /fapi/v1/exchangeInfo`中`deliverydate`为下架时间，请查询[获取交易规则和交易对](https://developers.binance.com/docs/zh-CN/derivatives/usds-margined-futures/market-data/rest-api/Exchange-Information) 提前获取合约交易对下架信息。
